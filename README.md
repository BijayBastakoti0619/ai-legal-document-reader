# AI Legal Document Reader and Summarizer

A full-stack application that allows authenticated users to upload PDF
documents and receive structured AI-assisted summaries.

## Technology Stack

### Backend
- Java 21
- Spring Boot
- Spring Security
- Spring Data JPA
- PostgreSQL
- Flyway
- Maven

### Frontend
- Angular
- TypeScript
- Angular Material

### Infrastructure
- Docker
- GitHub Actions
- Google Cloud
